## `01` Sobre mim

Sou **Victor Polonio**, desenvolvedor **Full Stack Júnior**. Trabalho com **TypeScript, React e Next.js** no front-end e com **C#, .NET e Node.js** no back-end.

Por aqui, reúno projetos de gestão clínica, um backend para transporte escolar e universitário e um temporizador de foco com ESP32. Eles mostram diferentes partes do que venho construindo: interfaces, APIs, regras de negócio e até um pouco de hardware.
